# Day 2 - React hooks, Context and Redux Toolkit (lessons 01 to 22)

```powershell
npm install
npm run dev        # http://localhost:5173
npm run build
```
Each lesson is one self-contained file in `src/steps` (`01-...jsx` to `22-...jsx`) with a banner comment, section comments, and a
`meta` object that feeds the lesson page. `src/App.jsx` is only the lesson viewer. Lesson list: see `../README.md`.
Lessons 04, 10 and 21 call the public API https://jsonplaceholder.typicode.com, so they need an internet connection.
